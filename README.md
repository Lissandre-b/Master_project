# Supplementary Material

This repository contains the supplementary material for my Master's thesis

**Signatures of Self-Interacting Dark Matter in Cosmological Zoom Simulations**

## Animations
- Orbits of stellar streams 2 and 3 : stream2.mp4 and stream3.mp4
- Orbits of stellar streams 3 with dm particles : stream3_dm_included.mp4
- Orbit in velocity space of stellar streams 2 and 3 : vel_stream2.mp4 and vel_stream3.mp4

The simulations compare CDM and several SIDM models.
